# えいごのもり 🐥

小学生向け英単語・英会話アプリ（単一HTML PWA）。孫用。

- 本番: https://soomine-svg.github.io/eigonomori/ （GitHub Pages・pushで即反映）
- 単語563語＋フレーズ89文＋会話レッスン18本＋英和辞書4.5万語（EJDict, パブリックドメイン）＋日本のことば138語
- 学習記録・今日の振り返りクイズ・記録の引っこしコード（バックアップ）つき
- 音声はWeb Speech API（端末内蔵TTS・通信不要）

## 構成

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体（約100KB） |
| `dict.txt` | EJDict英和辞書データ（4.4MB・Service Workerがキャッシュ） |
| `sw.js` | オフライン対応・通信節約（本体はネット優先＝更新即反映） |
| `manifest.webmanifest` | ホーム画面インストール用 |
| `gas/camera-translate.gs` | カメラ翻訳のGASバックエンド（設置手順はファイル冒頭） |
| `icon-180/192/512.png` | ホーム画面アイコン（未設置。画像が届いたら生成） |

## 更新の流れ

このrepoにpushするだけ。孫のスマホは次にアプリを開いたときに自動で新版になる（ホーム画面の入れ替え不要）。
